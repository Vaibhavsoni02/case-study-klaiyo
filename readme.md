# Klaiyo Case Study Extractor

**Created:** 2024-08-22

## Problem
Case-study content from Klaiyo pages was tedious to copy and structure by hand.

## Solution
A Streamlit app that parses HTML and extracts headers, body text, and links into a table.

## Outcome
Faster research summaries from case-study pages in a shareable live app.
